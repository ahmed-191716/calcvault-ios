# CalcVault - تطبيق الآلة الحاسبة والخزانة السرية لإخفاء البرامج (iOS 27)

تطبيق متطور ومموه بالكامل بصيغة **آلة حاسبة أصلية** لنظام iOS، مبرمج بلغة **Swift (SwiftUI)** ومتوافق تماماً مع **iOS 27**.

---

## 🛡️ الميزات الأمنية والتقنية

1. **التمويه الكامل (Decoy Interface):**
   * يظهر التطبيق في الهاتف باسم **Calculator** وبأيقونة الآلة الحاسبة الرسمية لآبل.
   * آلة حاسبة حقيقية 100% تقوم بجميع العمليات الرياضية الطبيعية.
   * لا يمكن لأي شخص يفتش الهاتف ملاحظة أي اختلاف.

2. **الفتح السري (Stealth Trigger):**
   * كتابة الرمز السري ثم الضغط على زر المساواة (`=`).
   * إذا كان الرقم هو رمزك السري: تفتح الخزانة فوراً.
   * إذا كان رقماً عادياً: تحسب الآلة النتيجة الرياضية كأي آلة حاسبة طبيعية دون إظهار أي رسالة خطأ تثير الشك.

3. **حماية الإكراه (Duress Passcode / Fake Vault):**
   * إذا أُجبرت على فتح الهاتف والتطبيق تحت التهديد، يمكنك إدخال **رمز الإكراه البديل**.
   * يفتح التطبيق واجهة وهمية بريئة تماماً تحتوي على "ملاحظات تسوق ويوميات عادية" دون أي أثر للبرامج المخفية.

4. **إخفاء التطبيقات الحقيقي (Screen Time API):**
   * استخدام واجهات آبل الرسمية `FamilyControls` و `ManagedSettings`.
   * إخفاء التطبيقات المختارة من الشاشة الرئيسية، مكتبة التطبيقات (App Library)، ونتائج البحث (Spotlight) بضغطة زر واحدة.

5. **تشفير حقيقي محلي 100% (Zero Cloud - Zero Cost):**
   * تشفير عسكري **AES-GCM 256-bit** للملاحظات والملفات عبر `Apple CryptoKit`.
   * حفظ قيم الهاش والأملاح العشوائية المشفرة داخل **iOS Keychain** المؤمن بالـ Secure Enclave.
   * لا توجد أي سيرفرات أو قواعد بيانات خارجية (يعمل محلياً بالكامل ومجاني 100%).
   * قفل فوري ومسح مفاتيح التشفير من الذاكرة RAM بمجرد الخروج من التطبيق.

## 💻 طريقة التثبيت على الآيفون وأنت تستخدم نظام ويندوز (Windows)

بما أنك على ويندوز، لا تحتاج لشراء ماك! لقد قمنا بتجهيز ملف أتمتة سحابي (**GitHub Actions**) يقوم ببناء ملف التطبيق `CalcVault.ipa` لك مجاناً:

### الخطوة 1: رفع المشروع على مستودع GitHub خاص (Private)
1. افتح موقع [GitHub](https://github.com) وأنشئ مستودعاً جديداً خاصاً (Private Repository).
2. ارفع ملفات هذا المشروع إلى المستودع:
   ```bash
   git add .
   git commit -m "Initial commit for CalcVault"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```

### الخطوة 2: استلام ملف التطبيق المترجم (.ipa)
1. في صفحة مستودعك على GitHub، اضغط على تبويب **Actions**.
2. ستجد سيرفر الماك السحابي يقوم ببناء التطبيق تلقائياً (Build & Package IPA) خلال دقيقتين.
3. بعد اكتمال البناء، ستجد ملفاً جاهزاً للتحميل باسم **`CalcVault-IPA`**. قم بتنزيله وفك الضغط عنه لتحصل على `CalcVault.ipa`.

### الخطوة 3: التثبيت على الآيفون عبر برنامج Sideloadly (لويندوز)
1. حمّل برنامج **[Sideloadly](https://sideloadly.io/)** المجاني على جهازك الويندوز.
2. وصّل الآيفون بالكمبيوتر باستخدام كيبل الـ USB.
3. افتح برنامج Sideloadly:
   * اسحب ملف `CalcVault.ipa` وأفلته داخل البرنامج.
   * أدخل بريدك لحساب Apple ID (المجاني الخاص بك لتوقيع التطبيق).
   * اضغط على **Start**.
4. خلال 30 ثانية، سيظهر تطبيق الآلة الحاسبة على شاشة هاتفك مباشرة!

### الخطوة 4: التفعيل على الآيفون
1. افتح في الآيفون: **الإعدادات > عام > إدارة الجهاز (VPN & Device Management)** واضغط على حسابك ثم **الوثوق (Trust)**.
2. افتح تطبيق الآلة الحاسبة، وأدخل رمزك السري لأول مرة واضغط على `=`.
3. اضغط على "منح الصلاحية" لتفعيل ميزة إخفاء التطبيقات عبر `Screen Time`.
